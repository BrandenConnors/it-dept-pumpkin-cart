## Fit and printing notes

- **00C_front_mount_TEMPLATE_2mm.stl:** PRINT FIRST. Thin fit template ONLY, never use to carry the cart. Chassis holes are the slotted row; round holes belong to floor bolts.
- **00D_rear_mount_TEMPLATE_2mm.stl:** PRINT FIRST. Thin fit template ONLY, never use to carry the cart. Chassis holes are the slotted row; round holes belong to floor bolts.
- **00_fit_coupon.stl:** Print FIRST with 00b: slots from notched end are 4.2/4.4/4.6 mm
- **00b_fit_peg.stl:** Print FIRST with 00: use this separate 4.0 mm peg to test the slots
- **00E_M3_insert_fit_test.stl:** Test 4.0 mm first. Pockets 3.8 to 4.8 mm, depth 6.7, for assumed 5.7 mm insert. Choose secure fit without bulging; measure longer/larger inserts before use.
