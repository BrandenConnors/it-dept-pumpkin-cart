# 01 Frame

Use the master [build guide](../../Documentation/Build_Guide.pdf). STL files use millimeters and retain their supplied print orientations. One STL is one piece; print the quantities below.

| STL | Quantity | Status |
|---|---:|---|
| 01_floor_rear.stl | 1 | Required |
| 02_floor_front.stl | 1 | Required |
| 03_floor_splice_print_4.stl | 4 | Required |

## Fit and printing notes

- **01_floor_rear.stl:** v06 flat-face print fix: mounting face DOWN, rails UP. 7 mm web. No supports under main floor; brim recommended. Insert and mounting locations retained.
- **02_floor_front.stl:** v06 flat-face print fix: mounting face DOWN, rails UP. 7 mm web. No supports under main floor; brim recommended. Insert and mounting locations retained.
- **03_floor_splice_print_4.stl:** Four 8 mm insert splices. Install inserts in top face BEFORE assembly. Eight M3x16 bolts.
