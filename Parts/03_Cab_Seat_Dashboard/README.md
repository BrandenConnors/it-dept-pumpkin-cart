## Fit and printing notes

- **06_seat_pedestal.stl:** Prototype; verify fit before final printing
- **07_bench_seat.stl:** Print on bench end; inspect new bosses/supports. Insert pockets in four side pads. Armrest M3x8, bench to pedestal M3x16.
- **08_armrest_print_2.stl:** Print flat as supplied. Two M3 x8 through side lugs into bench inserts. Fit before attaching bench.
- **12_dashboard.stl:** Enable supports for the recessed dashboard face and leg details; inspect slicer preview
- **13_steering_wheel_and_column.stl:** Wheel face DOWN, column UP. M3x35 through hub/column into insert installed at rear of dash boss. Decorative fixed wheel.
